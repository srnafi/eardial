The card has been rebuilt around the three things you look at: the device name,
the two ears, and what is coming out of them.

### What's new

- **Live level meters.** Each ear slider now carries a bright bar inside its
  fill that tracks the real peak on that channel, so a quiet side is visibly a
  setting problem rather than an audio one.
- **The device header says what the device is.** The dropdown shows
  `Bluetooth · Stereo`, `Output · Single channel`, and so on, and swaps in a
  Bluetooth glyph for wireless endpoints.
- **The pin is now a padlock.** It locks the card in place instead of pinning
  it above other windows. While locked the card cannot be dragged, but every
  control still works. The lock is remembered between runs.
- **The card remembers where you put it.** Drag it once and it comes back to
  the same spot on the next start, as long as that spot is still on a screen.
- **Quit is visible.** A Quit row at the bottom of the settings drawer, beside
  the Bluetooth fix. Right-clicking the card still works too.
- **Redrawn icons** at a consistent weight, including a larger dropdown
  chevron. The slider knobs gained a hover ring, and the knob itself no longer
  grows past its own edge at the track ends.

### Install

Download `LeftRightAudioBalancer.exe` and run it. Self-contained: no runtime to
install.

The exe is unsigned, so Windows may warn on first run. Verify the SHA256 above
if you want to check the download.
