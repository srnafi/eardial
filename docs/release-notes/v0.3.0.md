The card used to disappear when you pressed Win+D, and it did not come back on
its own. It now stays on the desktop where you left it.

### What's new

- **The card survives Show Desktop.** It is raised above the desktop layer when
  Show Desktop runs, so the volume you set stays in reach instead of needing a
  second Win+D to find again.
- **It still stays out of the way.** Focus an app and the card drops behind it
  as before. It is only raised while the desktop itself is what you are looking
  at, so it never covers a window you are working in.

### Fixed

- The card was placed below the desktop windows themselves rather than just
  below normal windows. That is why Show Desktop took it along with everything
  else, and why it stayed hidden afterwards.
- Desktop detection could be fooled by any always-on-top overlay on screen, such
  as a VPN or chat badge. The foreground window is now what decides whether the
  desktop is in view.
- Window cloaking was being read from the wrong attributes, so that filter never
  matched anything. It now uses the attribute Windows actually reports.

### Install

Download `LeftRightAudioBalancer.exe` and run it. Self-contained: no runtime to
install.

The exe is unsigned, so Windows may warn on first run. Verify the SHA256 above
if you want to check the download.
