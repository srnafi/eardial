The card kept climbing over your windows. Click the taskbar, or click the
wallpaper behind a window, and it would jump to the front and stay there. It
now stays at the back of the desktop, where it was always meant to be.

### Fixed

- **The card no longer jumps over your windows.** 0.3.0 raised it above the
  desktop layer so Show Desktop could not take it away, but that also let a
  click on the taskbar or on the wallpaper drag it over everything else. The
  card is never topmost now, so those clicks leave it where it is.
- **Show Desktop still shows it.** It sits against the desktop itself, so
  Win+D leaves it on screen with the wallpaper instead of hiding it along with
  everything else.
- **It no longer takes focus when it starts.** The card starts inactive, so it
  drops to the desktop immediately rather than waiting for you to click
  somewhere else first.

### Install

Download `LeftRightAudioBalancer.exe` and run it. Self-contained: no runtime to
install.

The exe is unsigned, so Windows may warn on first run. Verify the SHA256 above
if you want to check the download.
